Gradient Flow

Animated Gradient Text

Gradient Moving Text

.gradient-text {
  background: linear-gradient(90deg,
    #ff6b6b, #feca57, #48dbfb,
    #a29bfe, #ff6b6b);
  background-size: 300% 100%;
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
  animation: gradientMove 5s linear infinite;
}
@keyframes gradientMove {
  to { background-position: 300% 50%; }
}

Rotate In

Rotate + Scale Intro

Rotate In Text

.rotate-in {
  animation: rotateIn 1.2s ease-out both;
}
@keyframes rotateIn {
  from {
    opacity: 0;
    transform: rotate(-180deg) scale(.3);
  }
  to {
    opacity: 1;
    transform: rotate(0) scale(1);
  }
}

Blur Reveal

Blur to Clear Text

Blur Reveal

.blur-reveal {
  animation: blurReveal 2.2s ease-out both;
}
@keyframes blurReveal {
  0% {
    filter: blur(12px);
    opacity: 0;
    transform: scale(1.1);
  }
  100% {
    filter: blur(0);
    opacity: 1;
    transform: scale(1);
  }
}

Neon Flicker

Flickering Neon Sign Effect

Flicker Neon Text

.neon-flicker {
  color: #39ff88;
  text-shadow:
    0 0 5px #39ff88,
    0 0 10px #39ff88,
    0 0 20px #39ff88,
    0 0 40px #00ff66;
  animation: flicker 2s infinite;
}
@keyframes flicker {
  0%, 19%, 21%, 23%, 25%, 54%, 56%, 100% {
    opacity: 1;
  }
  20%, 24%, 55% { opacity: .25; }
}

3D Rotating Text

3D Flip Text

.flip-3d {
  display: inline-block;
  animation: flip3d 3s infinite;
  transform-style: preserve-3d;
}
@keyframes flip3d {
  0% {
    transform: rotateY(0);
  }
  50% {
    transform: rotateY(180deg);
  }
  100% {
    transform: rotateY(360deg);
  }
